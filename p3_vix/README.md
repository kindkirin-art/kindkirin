# 역P3: P3 신호를 거꾸로 써서 VIX 숏볼 (2026-11-22)

P3(위기 바닥에서 QQQ 매수)의 단계를 VIX에 거울처럼 대응시켰습니다. P3가 "주가 바닥"을 기다리는 동안, 같은 단계에서 "VIX 정점"을 확인하고 변동성을 팝니다(숏볼).

```
python states.py       # P3 v2 단계·사건 (p3_macro 데이터 사용)
python vix_rules.py    # 단순 규칙 비교 → rules.csv
python mirror.py       # 역P3 규칙과 변형 (2011~ 실제 VIXY) → mirror_variants.csv
python spot_check.py   # VIX 현물(1990~)로 매매 시점 검증 → spot_trades_*.csv
```
`p3_macro/`(P3 백테스트)가 옆 폴더에 있어야 합니다.

## 왜 숏볼인가: P3 단계별 VIX (1990~2026, VIX 현물)
| P3 사건 | 그날 VIX 중앙값 | 5일 뒤 | 20일 뒤 | 60일 뒤 | 20일 안 최고 |
|---|---|---|---|---|---|
| 감시 시작 | 28.4 | −6% | −23% | −32% | +8% |
| 연준 항복 | 31.0 | −12% | −21% | −34% | **0%** |
| 첫 반등 | 30.6 | −5% | −15% | −19% | +6% |
| 1차 매수 | 31.0 | +4% | +1% | −22% | **+19%** |
| 2차 매수 | 37.8 | +5% | −11% | −23% | +12% |
| P3 손절 | 38.9 | −15% | −11% | −28% | +13% |

- 감시 시작 15번 중 14번은 60일 뒤 VIX가 더 낮았습니다(예외 2008-01, +1%). P3가 감시를 시작할 때는 이미 VIX가 비싼 자리입니다.
- **연준 항복일이 VIX 정점과 거의 겹칩니다.** 20일 안 최고 상승 중앙값이 0%입니다.
- 반대로 1차 매수(이중바닥 재시험) 뒤에는 VIX가 다시 튑니다(2008-09 리먼, 2001-09). P3의 '첫 반등은 함정'이 VIX에서는 '재상승'으로 나타납니다.
- 숏볼이 크게 깨진 구간(2015-08 −25%, 2018-02 −31%, 2020-02~03 −62%, 2024-08 −26%, −0.5배 기준)은 대부분 **P3가 아직 대기(IDLE)일 때** 시작됐습니다. 위험은 위기 초입에 있고, P3 감시가 켜진 뒤에는 보상이 큽니다.

## 규칙 (채택안)
| P3 | 역P3 (VIX) |
|---|---|
| 1 감시 시작 (QQQ −15% + 배관 경보) | 같음. 감시 시작 이후 VIX 최고 종가 Vmax 기록 |
| 2 연준 항복 / 3 첫 반등 | **숏볼 1차(자금의 반)**: 연준 조치 확인 또는 VIX 종가 ≤ Vmax × 0.80 (VIX 정점 확인) |
| 4 1차 매수 | 새 진입 없음 (VIX 재상승 구간) |
| 5 2차 매수 (신용 정상화) | **숏볼 2차(나머지 반)** |
| 손절 (QQQ < 1차가 × 0.90) | VIX 종가 > 진입 VIX × 1.25 이거나 P3 손절일 → 전량 환매, Vmax 갱신 후 다시 정점 확인 대기 |
| 매도 (P1 TQQQ 재진입) | 전량 환매, 대기 |

매매 대상: SVXY 방식(VIX 단기선물 지수 −0.5배). 쉬는 돈은 T-bill. 모든 판단은 종가.

## VIX 현물로 본 매매 시점 (1990~, `spot_trades_base.csv`)
- 34번 중 16번이 VIX 하락으로 끝났습니다. 2000~02·2008처럼 긴 하락장에서는 손절이 여러 번 나고, 마지막 국면(2002-08→2003-03 VIX −25%, 2008-11→2009-06 −65%, 2020-03→05 −63%)에서 크게 법니다. P3와 같은 구조입니다.
- 종가 손절이라 하루 이틀에 VIX가 크게 뛰면 진입 대비 +59%(2010-05)까지 역행한 뒤 손절된 적도 있습니다.

## 채택하지 않은 것
- **1차 매수 뒤 롱볼(VIXY)**: P3 1차 매수 뒤 VIX가 다시 오르는 경향은 있지만, 롱볼은 선물 롤 비용이 커서 2011~ −1.5%/년이었습니다.
- **평시 캐리 + P3 차단**: 경보가 없고 콘탱고일 때 숏볼을 들고 P3 감시 중에는 쉬는 방식. 2018-02·2024-08처럼 P3가 대기일 때 터지는 급등을 막지 못해 MDD −53%였습니다.
- **감시 시작 즉시 숏**: CAGR 4.6%로 조금 높지만, 2008-01·2020-03-09처럼 감시 시작 뒤 VIX가 +33~52% 더 오른 경우가 있어 정점 확인을 남겼습니다.

## 데이터와 한계
- VIXY(2011-01~)는 실제 값입니다. 숏볼은 `−0.5 × (VIXY − T-bill + 보수) + T-bill − 0.95%`로 만들었습니다. 2018-03~ 실제 SVXY는 2.02배, 모델은 2.40배라 연 1%p 남짓 좋게 나옵니다.
- 2006~2010은 VIX·VIX3M 회귀로 대체값을 만들어 봤지만, 롱볼 2008년 +409%처럼 실제보다 크게 부풀어서 금액 결과에서 뺐습니다(`vix_rules.py`의 '대체값 구간' 행은 참고만).
- 2011~ 숏볼 매매 11번, 연준 항복이 있는 위기는 2020·2023 두 번뿐입니다. 통계적 결론을 내기엔 적습니다.
- 매매 비용, 세금, SVXY 괴리는 넣지 않았습니다.

## 현재 (2026-11-20 종가)
P3는 대기(배관 경보 없음)라 역P3도 대기입니다. VIX 35.9, VIX3M 30.9로 백워데이션이고 QQQ는 −19.9%입니다. 숏볼 위험이 가장 큰 '위기 초입' 모습이라 규칙상 진입하지 않습니다. 경보가 켜져 P3 감시가 시작되면 그날부터 Vmax를 기록하고, VIX가 Vmax의 80% 아래로 마감하거나 연준이 완화하면 반을 들어갑니다.

# P3에 VIX 필터 붙이기 (`p3_filter.py`, `filter_grid.py`)

역P3 숏볼은 같은 날짜에 QQQ를 산 것과 상관 0.75, 베타 1.0이라 따로 운용할 이유가 약했습니다(같은 신호로 QQQ 1배: 연 3.53%/MDD −17.3%, 숏볼: 3.89%/−16.8%). 그래서 VIX를 매매 대상이 아니라 **P3 매수 필터**로 시험했습니다.

```
python filter_grid.py   # 필터 비교 → filter_grid.csv
```
VIX는 1990-01부터 있어서 1986~87년 매수는 필터 없이 그대로입니다.

## 시험한 필터
| 필터 | 뜻 |
|---|---|
| 1차: VIX ≤ L일 VIX × k | 바닥 재시험 때 VIX가 첫 바닥보다 낮음 (다이버전스) |
| 1차: VIX ≤ 감시 후 최고 × k | VIX가 위기 정점에서 내려옴 |
| 1차: VIX ≤ n일선 × k | VIX가 다시 오르는 중이 아님 |
| 2차: VIX ≤ 30·40, 최고 × 0.6 | 2차 매수를 VIX가 충분히 내려온 뒤로 미룸 |

L일 VIX 기준값 민감도: ×1.00 1.63배 · ×0.95 1.61 · **×0.90 2.03 · ×0.85 2.03** · ×0.80 2.27 · ×0.75 2.17 · ×0.70 1.77.

- ×0.80이 가장 좋지만 2020-03-20 매수가 아슬아슬하게 통과합니다(VIX 66.0, 기준 66.2). 하루만 VIX가 조금 높았으면 2020년 이익을 놓칩니다. ×0.85~0.90은 결과가 같은 평평한 구간이고 2020년 여유도 커서(기준 74.4) 후보로 골랐습니다.
- 이동평균 필터는 기준값에 따라 결과가 들쭉날쭉해서 버렸습니다. 2차 매수에 VIX 조건을 붙이면 오히려 나빠졌습니다(2차 매수가 늦어져 상승을 놓침).
