# TQQQ 200일선 추세추종 + SCHD 단계 익절 백테스트 (2016-11-03 ~ 2026-11-02)

## 규칙
- 신호: TQQQ 종가 vs TQQQ 200일선. 3일 연속 위 → 3일째 종가 매수, 2일 연속 아래 → 2일째 종가에 TQQQ·SCHD 전량 매도
- 익절 전환(매수가 대비 TQQQ 수익률, 사이클마다 1회): +20% → 25%, +50% → 25%, +100% → 50%, +200% → 50%를 SCHD로 (각 시점 남은 TQQQ 기준)
- 전량 매도 후 대기자산: **SGOV**(2020-06 이전은 BIL) vs **GLD**
- 수정주가(배당 재투자), 거래비용·세금·슬리피지 미반영

## 결과

| **전략 + GLD 대기** | 44.95 | 46.3% | -30.6% | 30.8% | 1.40 |

# 닷컴버블 포함 장기 백테스트 (1991-01-02 ~ 2026-11-03)

규칙은 위와 동일. 상장 전 구간은 대체 데이터 사용:
- **TQQQ**: 3 × QQQ 일간 총수익 − 보수 0.95% − 2×(T-bill + 0.85%) 로 합성 (QQQ 상장 전은 ^NDX). 스프레드는 2010~2026 실제 TQQQ와 최종값이 맞도록 보정했고, 2010-02-11부터는 실제 TQQQ 사용
- **SCHD**: 2011-10 이전 Vanguard Value Index(VIVAX)
- **SGOV**: 2020-06 이전 BIL, 2007-05 이전 13주 T-bill(^IRX)
- **GLD**: 2004-11 이전 금 선물(GC=F), 2000-08 이전 월평균 금 가격(`data/gold_monthly_1985_2001.csv`) 일간 보간
