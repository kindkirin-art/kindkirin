|---|---|---|---|
| 레버리지 나스닥 | 25% | TQQQ 자체 200일선 (3일 연속 위 매수 / 2일 연속 아래 매도). 매수가 대비 +20/+50/+100/+200% 도달 시 TQQQ 잔량의 25/25/50/50%를 SCHD로 전환. 매도 신호 시 TQQQ와 SCHD 모두 매도 → SGOV | QLD, ^IXIC 200일선 (3일 연속 위 매수 / 2일 연속 아래 매도). 미보유 시 SGOV |

연말(마지막 미국 거래일 종가) 리밸런싱. 신호는 당일 종가 체결. Yahoo Finance 수정종가. 거래비용, 세금, 슬리피지는 빼고 계산.
연말 리밸런싱 때 TQQQ 칸 내부 구성비(TQQQ/SCHD/SGOV)는 유지하고, TQQQ 추가 매수분은 매수가(평단)에 반영.
