# TQQQ 200일선 추세추종 + SCHD 단계 익절 백테스트 (2016-11-03 ~ 2026-11-02)

## 규칙
- 신호: TQQQ 종가 vs TQQQ 200일선. 3일 연속 위 → 3일째 종가 매수, 2일 연속 아래 → 2일째 종가에 TQQQ·SCHD 전량 매도
- 익절 전환(매수가 대비 TQQQ 수익률, 사이클마다 1회): +20% → 25%, +50% → 25%, +100% → 50%, +200% → 50%를 SCHD로 (각 시점 남은 TQQQ 기준)
- 전량 매도 후 대기자산: **SGOV**(2020-06 이전은 BIL) vs **GLD**
- 수정주가(배당 재투자), 거래비용·세금·슬리피지 미반영
