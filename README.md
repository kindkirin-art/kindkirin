# 포트폴리오 백테스트 (2016-10-31 ~ 2026-10-30)

| 자산 | 비중 | 규칙 |
|---|---|---|
| QLD | 25% | 나스닥종합(^IXIC) 200일선. 3일 연속 위 → 3일째 종가 매수 / 2일 연속 아래 → 2일째 종가 매도. 미보유 시 SGOV |
| 금 (GLD) | 30% | 보유 |
| 비트코인 | 30% | BTC 120일선. 종가 > 120일선이면 보유, 아래면 당일 종가 매도 (대기 없음). 미보유 시 SGOV |
| SGOV | 15% | 2020-06 상장 전은 BIL로 대체 |

연말(해당 연도 마지막 미국 거래일 종가)에 리밸런싱. 데이터: Yahoo Finance 수정종가. 거래비용, 세금, 슬리피지는 빼고 계산.

## 비교 방식
- **추세추종 포트폴리오**: 위 규칙 그대로
- **장기보유 포트폴리오**: QLD 25%만 200일선 신호 없이 계속 보유하고, 나머지(금, 비트코인 120일선, SGOV, 연말 리밸런싱)는 동일
