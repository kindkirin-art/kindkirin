# 비트코인·금 포트폴리오 백테스트 (2016-10-31 ~ 2026-10-30)

공통 BTC 신호: 120일선, 대기 없음. 종가 > 120일선이면 당일 종가 매수, 아래면 당일 종가 매도. 미보유 시 SGOV(2020-06 상장 전은 BIL).
데이터: Yahoo Finance 수정종가 (BTC-USD, GLD). 거래비용, 세금, 슬리피지는 빼고 계산.

| 전략 | 규칙 |
|---|---|
| **동시 보유** | BTC(120일선) 50% + 금 50%, 연말(마지막 미국 거래일) 리밸런싱 |
| **스위치** | 매수신호 시 전액 BTC. 매수가 대비 +25%/+50%/+100%/+200% 도달 시 BTC 잔량의 25%/25%/50%/50%를 금으로 전환. 매도신호 시 BTC·금 모두 매도 후 현금 대기 |

BTC 신호 사이클 40회 중 29회는 +25%에 닿기 전에 매도되어 금전환 없이 끝남. +200%(4단계)까지 간 사이클은 3회(2017, 2019, 2020~21).
