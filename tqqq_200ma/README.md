# TQQQ 200MA 추세추종 + SCHD 익절 — SQQQ / TAIL 10% 헤지 추가전략 비교

기간: 2016-11-07 ~ 2026-11-06 (10년), 데이터: yfinance 수정주가(배당 재투자), 종가 체결, 현금 이자 0%, 수수료 0%.

## 규칙
- 신호: TQQQ 종가와 TQQQ 200일 이동평균 비교
- 매수: 200MA 위에서 3일 연속 마감하면 매수 / 매도: 200MA 아래에서 2일 연속 마감하면 TQQQ·SCHD(·SQQQ) 전부 매도
- 익절(매매 1회당 1번씩, TQQQ 진입가 대비 수익률 기준): +20% / +50% / +100% / +200% 도달 시 그 시점 TQQQ 보유분의 25% / 25% / 50% / 50%를 SCHD로 전환
- **A(기본)**: 진입 시 100% TQQQ
- **B(추가전략)**: 진입 시 TQQQ 90% + SQQQ 10%, 3거래일 뒤 SQQQ를 TQQQ로 전환. 매도 신호가 먼저 오면 SQQQ도 함께 매도
- **C(추가전략)**: B와 같고 SQQQ 대신 TAIL(Cambria Tail Risk ETF). TAIL은 2017-04 상장이라 2016-11-09 첫 진입 때는 10%를 3일간 현금으로 보유

## 결과 (수수료 0%)

|---|---|---|---|---|---|

| B SQQQ 10% 추가 | 29.25x | 40.2% | -27.5% | 1.29 | 1.46 |
| C TAIL 10% 추가 | 29.72x | 40.4% | -27.5% | 1.29 | 1.47 |

수수료 0.1%를 적용하면 A 29.24x (CAGR 40.2%), B 28.27x (CAGR 39.7%), C 28.72x (CAGR 39.9%).

TAIL 상장 후(2017-04-07~) 구간만 보면 A 21.52x, B 20.46x, C 20.96x.

## 결론
- 순위: A 기본 > C TAIL > B SQQQ. TAIL은 SQQQ보다 손해가 절반 정도로 작지만, 그래도 헤지를 안 하는 것보다는 못합니다.
- TAIL은 변동성이 작아서 3일 동안 거의 움직이지 않습니다. 그래서 TAIL 헤지는 사실상 '3일간 10%를 현금으로 두는 것'과 비슷하고, SQQQ처럼 하락장 보험 역할은 거의 못합니다.
- 추가전략(SQQQ 10%)은 10년 동안 최종배수 약 -3%, CAGR -0.4%p로 **약간 손해**이고, MDD는 같았습니다(-27.5%).
- 3거래일 동안 SQQQ 10%를 들고 있으면 사실상 TQQQ 비중이 약 80%(순노출)로 줄어듭니다. 그런데 200MA를 3일 연속 넘는 시점은 대개 상승 추세 초입이라, 헤지 비용이 대부분 손해로 이어집니다.
- 3일 안에 바로 매도된 휩쏘는 2025-05-20 진입(2일 만에 매도) 한 번뿐이었고, 그때는 헤지가 +0.75% 도움이 됐습니다. 나머지 휩쏘는 대부분 1주에서 2개월 뒤에 매도 신호가 나와서, 진입 후 3일만 헤지하는 구조로는 막지 못했습니다.
- 두 전략 모두 TQQQ 보유보다 CAGR이 높고, MDD는 -82%에서 -28%로 크게 줄었습니다.
