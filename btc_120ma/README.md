# 비트코인 120일선 추세추종 (대기 없음) — 1% 밴드 유무 비교

기간: 2015-01-14 ~ 2026-11-06 (BTC-USD 일봉, 주말 포함, 120일 단순이동평균). 종가 체결, 현금 이자 0%.

- 밴드 없음: 종가 > 120일선 → 당일 종가 매수, 종가 < 120일선 → 당일 종가 매도
- 1% 밴드: 종가 > 120일선×1.01 → 매수, 종가 < 120일선×0.99 → 매도, 그 사이는 현재 상태 유지

## 결론
- 수수료가 없으면 두 전략의 수익률은 사실상 같음(78.1% vs 78.0%).
- 1% 밴드는 매매 횟수를 52 → 33번(-37%)으로 줄여서 수수료가 있을수록 유리: 0.1%에서 CAGR +0.5%p, 0.2%에서 +1.0%p. MDD도 1.4%p 개선.
- 연도별로는 2023년(-13%p)처럼 밴드가 진입을 늦춰 손해 본 해도 있어, 매년 이기는 것은 아님.
- MDD -60%는 두 전략 모두 2017-12 고점 → 2019-03 저점. 고점에서 120일선 이탈까지의 하락에, 2018년 약세장 중 재진입 휩쏘(밴드 없음 6번, 1% 밴드 5번)가 겹친 결과. 밴드로는 크게 줄지 않음.
- 2% 이상 밴드는 오히려 나빠짐. 비트코인에서도 1% 밴드가 적당.

실행: `python3 backtest.py` → `equity_curves.csv` (수수료 0.1%)
