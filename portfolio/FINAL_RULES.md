# 최종 포트폴리오 규칙 (P1, 원화 투자자)

## 비중 (연 1회 리밸런싱: 매년 마지막 미국 거래일 기준)
| 자산 | 비중 | 매도 시 대기 |
|---|---|---|
| TQQQ 스위칭 (TQQQ + SCHD) | 40% | SGOV |
| 금 (KRX 금현물) | 30% | 원화 현금/MMF (필터 사용 시) |
| 비트코인 (업비트 BTC/KRW) | 20% | 원화 현금 |
| SGOV | 10% | - |

## 1. TQQQ 스위칭 (최적화 결과 현재 규칙 유지)
- 신호: TQQQ 일봉 종가 vs 200일 단순이동평균, 1% 밴드
- 매수: 종가 > 200일선×1.01 이 3일 연속 → 3일째 종가에 TQQQ 매수
- 매도: 종가 < 200일선×0.99 이 2일 연속 → TQQQ와 SCHD 전부 매도 → SGOV
- 익절: 진입가 대비 +20% / +50% / +100% / +200% 도달 시 그때 TQQQ 보유분의 25% / 25% / 50% / 50%를 SCHD로 (매매 1회당 각 1번)

## 2. 비트코인 (업비트 일봉, 09:00 KST 종가)
- 기본(최적화): 30일 단순이동평균, 2% 밴드, 대기 없음
  - 종가 > 30일선×1.02 → 매수 / 종가 < 30일선×0.98 → 매도 / 그 사이는 유지
  - 연 6회 정도 매매
- 대안(매매 적게): 120일선, 1% 밴드 (연 2~3회). P1 차이 CAGR 약 1%p, MDD 약 2%p

## 3. 금 (KRX 금현물, 원화)
- 기본: 보유 (장기 데이터·부트스트랩에서 필터 없는 보유가 약간 우세)
- 장기 금 약세장 보험을 원할 때: 원화 금 월봉 12개월 단순이동평균, 5%(또는 2%) 밴드, 2개월 확인
  - 월말 종가 < 12개월선×0.95 가 2개월 연속 → 금 매도
  - 월말 종가 > 12개월선×1.05 가 2개월 연속 → 금 재매수
  - 비용: 연 0.3~0.7%p 정도의 보험료. 1980~99형 금 약세장에서는 원화 금 MDD -45% → -28%

## 4. 실행 체크리스트
- 매일: TQQQ(미국 장 마감 종가), BTC(09:00 KST 종가)
- 매월 말: 금 월봉 신호(필터 사용 시)
- 매년 말: 목표 비중으로 리밸런싱
- 모든 판단은 종가 기준, 장중 돌파는 무시. 차트는 수정주가, 단순이동평균 사용

## 기대치 (과거 데이터 기준, 보장 아님)
- 2018~ 실제(원화, 최적화 규칙): CAGR 38% / MDD -16%
- 장기 부트스트랩(1999~, BTC 제외, 10년): CAGR 중앙값 약 13%, 하위 5% 약 2%, MDD 중앙값 -35%
- P2(TQQQ 50 / BTC 30 / SGOV 20)는 수익 중앙값이 비슷하거나 낮고 MDD -40% 초과 확률이 높아 비추천
