- 비트코인: 120일선 1% 밴드, 대기 없음

## 결론
- 금 단독으로 투자한다면 추세추종은 의미 있음: 1980~1999 같은 20년 약세장에서 MDD를 -62% → -24%로 줄이고 수익을 플러스로 바꿈. 월봉 10개월 이평처럼 느린 신호가 효과적.
- 1999년 이후 금 강세장에서는 일봉 추세추종이 MDD는 줄이지만(-46% → -32%) CAGR을 2~4%p 깎음. 금은 200일선 근처 휩쏘가 잦음.
- **P1 포트폴리오 안에서는 금 추세추종이 오히려 나쁨**: MDD -24.1% → -29.4%. 2007-10~2009-07(포트폴리오 MDD 구간)에 금 보유는 +15.4%였지만 금 추세추종은 휩쏘로 -7.1%. 2008년 금융위기 때 금이 일시적으로 급락하며 매도 신호가 나왔다가 반등을 놓침. 주식 폭락기에 금을 계속 들고 있는 것이 금 비중의 핵심 역할.
- 권장: P1에서는 금을 그대로 보유. 금이 수년간 하락 추세인 장기 약세장이 걱정된다면 일봉 대신 월봉 10개월 이평 정도의 느린 필터만 고려.

## 금 10개월 이평 이탈 시 P1 → 50/30/20 전환 (`python3 gold_regime_switch.py`)
금 월말 종가가 10개월 이평 위면 P1(40/30/20/10), 아래면 TQQQ 50 / BTC 30 / SGOV 20. 2018년 이전은 BTC 비중을 TQQQ로(60/30/0/10 ↔ 80/0/0/20). 전환 시점(월말)에 리밸런싱하고 거래금액의 0.1%를 비용으로 반영, 연말 리밸런싱은 동일. 1999년 이후 금 OFF 기간 33%, 전환 49회.

|---|---|---|---|
| 1999~2026 | 19.8% / **-24.1%** (**1.02**) | **20.0%** / -25.5% (0.98) | 21.7% / -35.0% (0.93) |
| 1999~2002 | 14.5% / -19.0% | 14.6% / -20.8% | 16.2% / -23.4% |
| 2003~2009 | **16.2% / -24.1%** | 14.9% / -25.5% | 14.2% / -35.0% |
| 2010~2017 | 14.4% / -20.4% | 15.8% / -22.4% | 17.1% / -28.7% |
| 2018~2026 | 30.3% / -15.4% | 30.4% / -15.4% | 34.8% / -20.1% |

### 10년 2016-11~ (처음부터 BTC 포함, portfolio_10y.py와 같은 비중)
| | P1 (금 보유) | P1 + 금 OFF 시 50/30/20 | P2 |
|---|---|---|---|
| CAGR / MDD | **45.8%** / -25.2% | 42.7% / **-22.1%** | 55.8% / -29.8% |
| Sharpe / Calmar | 1.77 / 1.81 | 1.78 / 1.93 | 1.73 / 1.87 |

(이 표의 P1은 데이터 연결과 TQQQ 스위칭 시작 상태가 portfolio_10y.py와 조금 달라 43.2x로, 43.98x와 약간 차이)

### 결론
- 효과는 거의 없음. 장기 CAGR +0.2%p를 얻는 대신 MDD -1.4%p 악화, Sharpe 하락. 결과적으로 P1과 P2 사이의 중간값에 가까움.
- 2010~2017(금 약세)에는 +1.4%p로 도움이 됐지만, 2003~2009(금융위기)에는 -1.3%p. 2008년 위기 중 금이 잠깐 10개월 이평을 이탈하면서 금을 팔고 TQQQ 비중을 늘린 것이 손해(2008년 -5.8% → -7.6%).
- 10년 테스트에서 CAGR이 3%p 낮아진 것은 금 필터 자체보다 리밸런싱 타이밍 영향이 큼: 2017-04/06/07 전환 때마다 BTC를 목표 비중으로 줄여서, 연말까지 보유했으면 얻었을 2017년 BTC 급등분 일부를 놓침(2017년 +286% → +199%).
- 권장: P1은 금을 고정 보유하고 연 1회 리밸런싱하는 원래 방식이 가장 단순하고 결과도 비슷하거나 우수.

- 예외는 2022-04 ~ 2022-11(금리 급등과 달러 강세): 금도 -13.8%. 모든 위험자산이 같이 떨어지는 긴축기에는 금도 방어하지 못함. 이때 P1 손실을 줄인 것은 금보다 TQQQ/BTC 매도로 생긴 현금(SGOV)이었음.
- 1999년 이후 TQQQ 매도 기간 전체로 보면 금 연환산 +6.3%로 평소보다 낮음(2006년 -19.9% 등). 다만 2000~2003 닷컴 붕괴(+19.0%, QQQ -66.8%)와 2008~2009 금융위기(+10.7%, QQQ -23.2%) 같은 큰 위기에서는 플러스.

- P2 대비 CAGR -0.9%p(장기)를 내주고 MDD는 1.1%p만 개선. Calmar는 P2보다 오히려 낮음(0.61 vs 0.62). P2보다 나은 점이 거의 없음.
- 금이 약세일 때 금을 30% 사는 역발상이라, 2013년(금 -28%)처럼 금 하락이 이어지는 해에 손해(P2 +68.7% → +43.1%). 반대로 2016년처럼 금이 바닥에서 반등한 해에는 이득(+0.4% → +6.2%).
- 금 신호로 P1/P2를 오가는 두 방향 모두 고정 비중(P1 또는 P2)보다 의미 있게 좋지 않음. 결과가 두 고정 포트폴리오 사이에 놓임.

## P2가 100% SGOV(현금)가 되는 기간
P2에서 TQQQ 스위칭(TQQQ+SCHD 매도)과 BTC가 모두 매도 상태인 기간(2018년 이전 장기 테스트는 BTC가 없어 TQQQ 매도 기간). 기간 비중: 1999~2017 37%, 2016-11~ 17%, 2018~ 20%. 1999년 이후 31번(30일 이상 19번). 구간 목록은 위의 "둘 다 매도였던 구간"과 "TQQQ-out episodes"(`python3 gold_when_risk_off.py`) 참고.
