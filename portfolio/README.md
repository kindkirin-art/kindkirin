# 포트폴리오 백테스트: TQQQ 스위칭(1% 밴드) + 금 + 비트코인(1% 밴드) + SGOV

기간 2016-11-07 ~ 2026-11-06 (10년). 실행: `python3 backtest.py`

- TQQQ 스위칭: TQQQ 200일선 1% 밴드. 200일선×1.01 위에서 3일 연속 마감하면 매수, 200일선×0.99 아래에서 2일 연속 마감하면 TQQQ와 SCHD 전부 매도. +20/50/100/200% 수익에서 25/25/50/50%를 SCHD로 전환
- 비트코인: 120일선 1% 밴드, 대기 없음
- 금: GLD / SGOV(2020-05 상장 전은 BIL)
- 전략이 매도 상태일 때의 현금은 SGOV 수익률을 받음. 전략 내부 매매 수수료 0.1%
- 매년 마지막 미국 거래일에 목표 비중으로 리밸런싱(리밸런싱 비용·세금 미반영)

## 결론
- P2(금 없음, BTC 30%)는 수익률이 높음: 10년 CAGR 56% vs 46%, 2017년 제외해도 35% vs 31%.
- P1(금 30%)은 위험 대비 효율이 높음: MDD -24.5% vs -30.3%(2017년 제외 시 -15% vs -20%), Sharpe와 Calmar 모두 P1이 우위. 2025년처럼 BTC·TQQQ가 약하고 금이 강한 해에 차이가 남(P1 +32% vs P2 +17%).
- 두 포트폴리오 모두 TQQQ 스위칭 단독보다 CAGR이 높고 MDD는 비슷하거나 낮음. 분산 효과가 큼.
- 10년 결과는 2017년 비트코인 급등의 영향이 매우 큼. 2017년을 빼면 P2의 우위가 크게 줄어듦.
- 고르는 기준: 수익 극대화는 P2, 낙폭과 변동성을 줄이려면 P1.
